# 创作者建世界模板（万界人生模拟器）

> 分工：**你负责"想故事"，我负责"落文件 + 验证 + 推送"。**
> 你只需要给我一段脑洞设定，其余全自动。照「永昼便利店」那次的节奏走即可。

---

## 一、你只需要准备：一段「四段式」题材设定（自然语言）

把你的脑洞写成下面四段，贴给我就行（有几句写几句，缺的部分我会帮你补全——就像我帮你补写了永昼便利店的 7 条员工守则）：

1. **主角 + 开场**
   - 主角是谁、什么身份、在什么时间/地点、开场第一幕的画面感是什么
   - 目标是什么（如"活到清晨 6 点"）、随身有什么关键物品（如"员工守则残页、老式翻盖手机"）

2. **世界法则 / 机制（如果有）**
   - 这个世界的超自然规则、禁忌、数值系统（如理智值/污染值/生存天数/物资）
   - 违反规则会怎样、哪个数值归零/拉满会失败

3. **关键人物 / NPC**
   - 名字、外貌特征（一个可辨认的记忆点）、性格、与主角的关系、隐藏的秘密

4. **剧情走向 + 结局 + 事件锚点**
   - 背后的真相是什么、通关/胜利条件是什么
   - 几个必须发生的高潮节点（发现线索 → 反转 → 决战）

> 你给得越具体，世界越有质感；给得模糊，我会按题材惯例帮你补全并标注「这是我补写的，你可改」。

---

## 二、我拿到设定后做什么（全自动，你不用管）

| 步骤 | 我做的事 | 产出 |
|---|---|---|
| ① 落文件 | 把设定转成两个文件 | `backend/worlds/<id>.json` + `backend/prompts/<id>_system_prompt.txt` |
| ② 验证 | 本地校验 + 状态引擎往返 + 全量测试 | 确认能加载、能结算、不破坏其它世界 |
| ③ 推送 | 推测试库 → 你确认 → 推正式库 | 见下方「推送铁律」 |

### ① 两个文件长这样（我生成，你只需了解，不用手写）

**`backend/worlds/<id>.json`** —— 世界规格（数值模型 + 创建向导）：

> ⚠️ **纯净 JSON 铁律**：下面代码块里的 `//` 注释仅供讲解说明；**实际落盘的 `.json` 文件里一律禁止出现任何 `//` 或 `/* */` 注释**，必须是 `json.load()` 能直接解析的纯 JSON。

```json
{
  "id": "yongzhou",                        // 小写英文唯一 id，上线后别改（旧存档靠它恢复）
  "name": "永昼便利店",                     // 广场卡片显示名
  "kind": "builtin",                       // 内置世界固定 builtin；owner 填 null = 人人可见
  "desc": "一句话简介（广场卡片用）",
  "rulebook_file": "backend/prompts/yongzhou_system_prompt.txt",
  "summary": "yongzhou",                   // 填世界 id；纯剧情无等级才填 "generic"
  "state_template": {
    "character": {
      "name": "无名", "gender": "?", "age": 22,     // 标量字段给默认值
      "身份": "永昼便利店夜班店员",                  // 固定字段（不进创建向导）直接用中文键，摘要里显示更好看
      "background": "", "secret": "", "traits": [],  // 这些键要和 creation_schema 对齐
      "day": {"init": 1, "min": 1, "max": 7, "max_step": 1}   // 等级字段 = 绝对目标 + 每轮限步
    },
    "level_field": "day",                  // 等级字段名，必须对应 character 里的键
    "resources": {"物资": {"init": 3, "min": 0}},               // 资源：增量，min 防止扣成负
    "stats": {                             // 属性：增量，max_step 限每轮幅度，min/max 限界
      "理智": {"init": 100, "min": 0, "max": 100, "max_step": 30},
      "污染": {"init": 0, "min": 0, "max": 100, "max_step": 30}
    },
    "affection_chars": ["老周", "小夏"],   // 好感/信任人物（开局全 0，可动态新增）
    "affection_min": -100, "affection_max": 100,
    "factions": [],                        // 势力（无就留空数组）
    "inventory": [],                       // 初始道具
    "start_location": "永昼便利店·夜班",
    "meta": {"rewind_left": 3}             // 后悔回退次数，默认 3
  },
  "creation_schema": {                     // 创建向导：驱动前端表单
    "steps": [
      {
        "step": "你是谁",
        "fields": [
          {"key": "name", "label": "姓名", "type": "text", "required": true},
          {"key": "gender", "label": "性别", "type": "select", "options": ["男", "女"], "required": true},
          {"key": "age", "label": "年龄", "type": "number", "min": 18, "max": 40, "default": 22}
        ]
      },
      {
        "step": "上岗之前",
        "fields": [
          {"key": "background", "label": "上夜班的理由", "type": "textarea", "rows": 2},
          {"key": "secret", "label": "心里的秘密", "type": "textarea", "rows": 2},
          {"key": "traits", "label": "性格特质", "type": "multiselect", "placeholder": "冷静, 胆小, 敏锐"}
        ]
      }
    ]
  }
}
```

> 字段类型：`text` / `textarea` / `number` / `select` / `multiselect` / `boolean`。
> **铁律：`creation_schema.fields[].key` 必须和 `state_template.character` 里的键一一对应**，否则创角填的值会被丢弃。

**`backend/prompts/<id>_system_prompt.txt`** —— 规则书（喂给 AI 的世界观+机制+输出契约），固定九节骨架：

```
# 角色设定
# 一、核心原则（置于一切之上）      → 玩家意愿最高、选项驱动、强制推进
# 二、世界观                        → 地点、时间、核心意象
# 三、专属设定（如员工守则/境界表） → 世界独有的规则条文
# 四、核心人物                      → 名字 + 外貌记忆点 + 性格 + 秘密
# 五、核心机制                      → 每个数值字段的含义 + 结算规则
# 六、剧情走向                      → 真相 + 通关条件 + 事件锚点
# 七、开局引导                      → 开场怎么起
# 八、文风与叙述约束（硬性规定）    → 禁用句式、选项写法、关键数字加粗
# 九、对 AI 引擎的输出契约（最高优先级）→ JSON 结算契约
```

最关键的**第九节（输出契约）**，`state_delta` 的键必须和后端严格对应：

```json
{
  "state_delta": {
    "resources": {"物资": -1},            // 增量（正负均可）
    "stats": {"理智": -10, "污染": 30},   // 增量
    "day": null,                          // 等级字段 = 绝对目标，没变写 null（绝不能写 0）
    "affection": {"小夏": 5},             // 增量，键是角色中文名
    "location": "永昼便利店·冷藏库",
    "date": "第1夜·凌晨2:47",
    "month_delta": 0,                     // 无月份概念的世界恒为 0
    "inventory_add": ["黄色工牌"], "inventory_remove": [], "notes_add": []
  },
  "notes": [], "event": ""
}
```
